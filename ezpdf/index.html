코어 PDF 열람 방법

ezPDF Reader로 코어 교재를 여는 방법을 화면 순서대로 정리했어요.
화면의 주황 테두리가 눌러야 할 곳이에요.

코어 시리즈 PDF는 보안이 적용된 전자책이라 일반 PDF 프로그램(크롬, 엣지, 어도비 등)으로는 열리지 않아요. ezPDF Reader를 설치하고 ezPDF 계정으로 로그인해야 볼 수 있어요. 암호는 따로 없어요.
1. 내려받기2. 리더 설치3. 파일 열기4. 로그인5. 인쇄모바일자주 묻는 질문
1

PDF 파일 내려받기

1-1메일의 내려받기 버튼을 눌러요

신청하신 메일 주소로 받은 메일에서 PDF 내려받기 버튼을 눌러 주세요.

1-2파일 다운로드 버튼을 눌러 기기에 저장해요

다운로드 버튼을 눌러 파일을 저장해요.

꼭 기기에 내려받아 주세요. 드라이브 미리보기 화면에 띄워 두기만 하면 열리지 않아요. 미리보기에 "Secured PDF File" 화면이 보이는 것은 정상이에요.
2

ezPDF Reader 설치하기 (PC)

2-1ezPDF Center에서 「ezPDF DRM 서비스 리더」를 받아요

ezPDF Center 다운로드 페이지 아래쪽의 ezPDF DRM 서비스 리더 항목에서 다운로드를 눌러요.

다른 프로그램(Editor Uno, Editor 4.0, Editor 3.0)은 받지 마세요. 반드시 「DRM 서비스 리더」를 받아야 해요.
2-2내려받은 설치 파일을 실행해요

다운로드 목록에서 ezPDF_DRM_Reader 파일의 파일 열기를 눌러요.

2-3설치 창에서 「다음」
2-4사용권 계약에서 「동의함」
2-5설치 완료 후 「마침」
3

코어 교재 파일 열기

3-1ezPDF Reader 3.0을 실행해요

바탕화면이나 시작 메뉴에서 ezPDF Reader 3.0을 실행해요. 찾기 어려우면 PC 검색창에 ez라고 검색해 보세요.

3-2「파일」 → 「열기」를 눌러요
3-3내려받은 코어 교재 파일을 골라요

보통 다운로드 폴더에 있어요. 파일 이름 앞에 [DRM]이 붙어 있을 수 있어요.

4

ezPDF 계정으로 로그인하기

4-1「로그인 필요」 창에서 「예」
4-2ezPDF DRM Service에 로그인해요

아이디가 없다면 무료회원가입을 먼저 해 주세요. 가입 후 같은 창에서 로그인하면 돼요.

4-3열람 완료

교재 표지와 쪽 목록이 보이면 정상적으로 열린 거예요.

5

인쇄할 때 꼭 확인해 주세요

5-1전체 페이지로 한 번에 인쇄해요
인쇄 횟수가 정해져 있어요. 인쇄 버튼을 누를 때마다 횟수가 1회씩 줄어요. 페이지를 나눠서 여러 번 인쇄하지 말고, 반드시 전체 페이지로 한 번에 인쇄해 주세요.
M

모바일(휴대폰·태블릿)에서 보기

  1. 앱스토어나 플레이스토어에서 ezPDF 뷰어 앱을 설치해요.
  2. 메일의 내려받기 버튼으로 PDF를 기기에 저장해요.
  3. 저장한 PDF를 ezPDF 뷰어 앱으로 열고, PC와 같은 ezPDF 계정으로 로그인해요.

자주 묻는 질문

"암호가 걸려 있다"는 화면이 나와요.

ezPDF가 아닌 다른 프로그램으로 열었을 때 나오는 화면이에요. 실제 암호는 없어요. ezPDF Reader(PC) 또는 ezPDF 뷰어 앱(모바일)으로 열어 주세요.

드라이브에서 "Secured PDF File"만 보여요.

정상이에요. 드라이브 미리보기로는 볼 수 없으니 다운로드 버튼으로 기기에 저장한 뒤 ezPDF로 열어 주세요.

ezPDF Center에서 어떤 프로그램을 받아야 하나요?

페이지 아래쪽의 「ezPDF DRM 서비스 리더」예요. Editor 프로그램들은 받지 않아도 돼요.

언제까지 볼 수 있나요?

일반적으로 시험일까지 횟수 제한 없이 볼 수 있어요. 교재에 따라 달라질 수 있어요.

인쇄 횟수 제한은 어떻게 되나요?

일반적으로 시험일까지 무제한 열람할 수 있고, 인쇄는 기본 1회에 여유분 2회를 더해 총 3회 제공돼요. 다만 교재에 따라 달라질 수 있어요. 인쇄 버튼을 누를 때마다 1회씩 줄어드니 전체 페이지로 한 번에 인쇄해 주세요.

그래도 안 열려요.
